# GPM User Guide

GPM helps you run, monitor, and automate long-running services and scripts from one place.

Use this guide to get the service running, manage processes and tasks, search logs, and control access for your team.

## Before you start

- Install GPM on the machine that will run your managed processes.
- Use a dedicated service account in production.
- Back up GPM data before upgrades or major configuration changes.
