# 日志存储与检索

GPM 会收集受管进程的输出，供你在管理界面中检索。

## 选择存储方式

| 方式 | 适合场景 | 使用注意 |
| --- | --- | --- |
| SQLite | 小规模部署和简单的本机运行。 | 不需要额外服务。 |
| Elasticsearch | 较大规模或需要集中检索日志的场景。 | 需要运行 Elasticsearch 并持续管理容量。 |
| Bleve | 希望在本机进行全文检索，但不想部署额外服务。 | 会占用本地磁盘，应纳入备份。 |

请按日志量和运维方式选择。切换存储方式不会自动搬迁历史日志，变更前请做好保留和备份计划。

## 检索日志

在日志搜索框输入一个或多个词：

- 用空格分隔多个词，表示结果需要同时满足它们。
- 用双引号包住短语，例如 `"out of memory"`。
- 在词前加 `~`，可查找作为更长消息一部分的内容。
- 在词前加 `!`，可排除包含该词的消息。

示例：

```text
error timeout
"out of memory"
~GET /api
error !debug
```

不同存储方式对全文、局部词和高亮的处理可能略有差别。用于告警的重要查询，请先用接近生产环境的日志验证。
