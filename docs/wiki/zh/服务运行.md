# 服务运行

GPM 可以在终端中运行，也可以注册为操作系统后台服务。

## 准备 GPM

下载发行版二进制文件，赋予执行权限，并放到稳定的目录中。首次启动时，GPM 会在启动用户的主目录下创建运行数据；请保证该目录可用并纳入备份。

## 前台运行

前台模式适合本地调试、测试，或由其他平台负责托管的场景：

```bash
./gpm run
```

服务会持续占用终端，使用 `Ctrl+C` 停止。

## 注册为系统服务

服务器环境建议先注册，再启动：

```bash
./gpm service install
./gpm service start
```

常用维护命令：

```bash
./gpm service stop
./gpm service restart
./gpm service uninstall
```

请使用同一个操作系统账户完成注册、运行和日常维护。该账户需要有权限运行 GPM，并访问你添加的受管进程及其工作目录。

## 启动后检查

1. 在浏览器打开 GPM 管理界面。
2. 使用管理员账户登录。
3. 先创建一个测试进程，再添加生产服务。
4. 修改设置或升级 GPM 后，重启服务。

## 运维建议

- 将 GPM 的数据目录放在持久化存储中。
- 限制主机和管理员账户的访问范围。
- 尽量使用服务命令停止 GPM，避免直接强制结束进程。
