# GPM 使用指南

GPM 帮助你在一个界面中运行、监控和自动化管理长期运行的服务与脚本。

本指南面向使用者，介绍如何运行服务、管理进程和任务、检索日志，以及为团队成员分配访问权限。

## 开始前

- 在需要运行受管进程的机器上安装 GPM。
- 生产环境建议使用专用服务账户。
- 升级或大范围调整设置前，请备份 GPM 数据。
