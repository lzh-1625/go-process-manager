# 命令行参考

命令行可用于维护本机上的 GPM。使用 `gpm --help` 或 `gpm <命令> --help` 查看帮助。

使用管理命令前，请先启动 GPM 服务。

## 服务命令

| 命令 | 作用 |
| --- | --- |
| `gpm run` | 在前台运行 GPM。 |
| `gpm service install` | 将 GPM 注册为系统服务。 |
| `gpm service start` | 启动已注册的服务。 |
| `gpm service stop` | 停止已注册的服务。 |
| `gpm service restart` | 重启已注册的服务。 |
| `gpm service uninstall` | 移除系统服务注册。 |
| `gpm version` | 查看已安装版本。 |
| `gpm config reset` | 恢复默认设置，会覆盖当前设置。 |

## 进程命令

| 命令 | 作用 |
| --- | --- |
| `gpm process list` | 查看你有权限访问的受管进程。 |
| `gpm process start NAME` | 启动进程。 |
| `gpm process stop NAME` | 停止进程。 |
| `gpm process exec NAME` | 在有权限时打开进程交互终端。 |

## 任务命令

| 命令 | 作用 |
| --- | --- |
| `gpm task list` | 查看已配置的任务。 |
| `gpm task start ID` | 手工启动任务。 |
| `gpm task stop ID` | 停止正在运行的任务。 |

## 其他管理命令

| 命令 | 作用 |
| --- | --- |
| `gpm user list` | 查看用户账户。 |
| `gpm user delete ACCOUNT` | 删除用户账户。 |
| `gpm push list` | 查看通知目标。 |
| `gpm push delete ID` | 删除通知目标。 |
| `gpm wsshare list` | 查看活动中的终端分享链接。 |
| `gpm wsshare delete ID` | 撤销终端分享链接。 |
| `gpm docker CONTAINER` | 在 Linux 上跟随并管理 Docker 容器。 |

日常管理通常使用 Web 界面更方便；命令行适合服务器维护和自动化操作。
