# 配置参考

通过设置页面调整 GPM 的运行方式。修改安全、网络、日志存储或资源限制前，建议先备份当前设置。

## 服务与安全

| 设置 | 作用 | 何时重启 |
| --- | --- | --- |
| 服务地址和端口 | 控制管理界面的访问位置。 | 修改后重启。 |
| 登录有效期 | 控制用户保持登录的时长。 | 新登录会使用新设置。 |
| 最小密码长度 | 为新建或修改密码设置安全要求。 | 通常不需要重启。 |
| 终端超时 | 在指定时间后关闭闲置终端。 | 新连接会使用新设置。 |

## 日志与存储

| 设置 | 作用 |
| --- | --- |
| 日志级别 | 控制 GPM 记录多少诊断信息。 |
| 日志存储 | 选择本地存储、Elasticsearch 或 Bleve。 |
| Elasticsearch 连接 | 配置外部日志服务的地址、索引和凭据。 |
| 日志处理能力 | 控制 GPM 可并行处理多少日志工作。 |
| 搜索结果行为 | 控制大规模 Elasticsearch 搜索结果的统计方式。 |

修改日志存储方式或外部连接后，请重启服务。外部服务凭据应妥善保管。

## 进程、任务与监控

| 设置 | 作用 |
| --- | --- |
| 重启次数限制 | 限制进程自动重启次数。 |
| 终端输出缓存 | 控制保留多少最近终端输出。 |
| 性能历史与采样间隔 | 控制保存多少性能数据以及采样频率。 |
| 停止等待时间 | 控制优雅停止时的等待时长。 |
| 任务超时 | 限制任务等待完成的最长时间。 |
| 终端连接健康检查 | 控制终端连接的健康检查频率。 |
| 页面更新等待时间 | 控制管理界面等待更新的时长。 |
| 事件保留时间 | 控制审计事件的保存时长。 |

## 资源限制与界面行为

| 设置 | 作用 |
| --- | --- |
| CPU 和内存控制 | 在支持的 Linux 环境中启用并调整资源限制。 |
| 诊断工具 | 启用性能排查工具；生产环境应谨慎暴露。 |
| 响应压缩 | 减少浏览器加载数据量。 |
| 静态内容缓存 | 提升管理界面加载性能。 |

## 安全修改步骤

1. 记录当前值或导出备份。
2. 每次只修改一组相关设置。
3. 大范围调整后重启 GPM。
4. 确认管理界面、进程列表和日志搜索仍可正常使用。
